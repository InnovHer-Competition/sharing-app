# Contributing

## Commit messages

Use a short conventional subject with one of these prefixes:

- `docs:` documentation-only changes
- `add:` new features or files
- `update:` behavior or configuration changes
- `fix:` bug fixes
- `chore:` maintenance and tooling
- `refactor:` structural changes without behavior changes

Write the subject in the imperative, keep it under 72 characters, and do not add AI co-author trailers.
